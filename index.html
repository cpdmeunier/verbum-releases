What Verbum is

A Mac app that sits between your voice and your AI agent. It listens, understands, and hands instructions to the agent you already use. Verbum doesn't draw: your agent does, in your design tool.

Listens
Mac dictation, transcribed on your machine when your Mac supports it.
Understands
A small, fast model turns what you say into design instructions and ignores small talk. Claude by default, or a local model.
Connects
An MCP server your agent plugs into. Claude Code today, other MCP agents next.
Draws
Your agent, through your design tool's own MCP server. Any tool that has one works.
Respects your project
Your codebase is read, never modified: colors, components and assets become the starting point.

Get started

You need
  • A Mac with Apple Silicon
  • Claude Code, signed in
  • A design tool whose MCP server is added to Claude Code. Check with claude mcp list.

  1. Install Verbum

    Download, open it and drag Verbum to your Applications folder. Allow the microphone and speech recognition when macOS asks. Verbum then updates itself.

  2. Connect it to Claude Code

    In the Verbum panel, click Install /verbum in Claude Code. Once.

  3. Open your design file

    In your design tool. That's the screen you (and your team) will watch.

  4. Start talking

    In your project folder, open Claude Code and type:

    /verbum

    It asks which design tool to draw in. When you're done, End writes a report of the session.
